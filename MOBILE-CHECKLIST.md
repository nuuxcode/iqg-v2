# Mobile checklist (manual)

After deploying, open the production URL on a real iPhone or Android and confirm:

- [ ] Input field is comfortable to tap and shows the keyboard
- [ ] All three selectors (Type + Difficulty) are tappable without zooming
- [ ] Generate button is reachable with thumb
- [ ] Questions render fully without horizontal scroll
- [ ] "3 More" button is visible and tappable
- [ ] History drawer slides in cleanly from the left
- [ ] Error banners are readable at default zoom
- [ ] Streaming animation doesn't cause layout shift

If any item fails, file a fix in `docs/build-history/`.
